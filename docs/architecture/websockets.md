## How the streams work

- **Transport.** `wss://<host>/fx-volatility-trading-system/ws/<name>` in prod
  (nginx strips the prefix), `ws://localhost/ws/<name>` locally. Each socket is a
  one-way stream: the api subscribes to one Redis channel and forwards every
  message to every client, verbatim, as a JSON text frame. Clients send nothing.
- **Access.** Public, like the REST reads. The upgrade is refused with close code
  1008 when the `Origin` header is not on the allowlist (`WS_ALLOWED_ORIGINS` +
  the CORS origins); a client that sends no `Origin` (not a browser) is accepted
  ([security.md](../ops/security.md#websocket-streams)).
- **Delivery.** At most once, no backlog: Redis pub/sub keeps nothing for a
  client that was not connected. After a reconnect, re-read the REST snapshot
  (the desk does this on every reconnect).
- **Types.** The frontend types for these messages live in
  `frontend/src/hooks/streams.ts` and are checked against the same fixtures
  (`frontend/src/hooks/__tests__/wsContract.test.ts`).

| Socket | Redis channel | When a message is sent | Desk reader |
|---|---|---|---|
| `/ws/ticks` | `ticks` | every tick, throttled to one PUBLISH per 200 ms per symbol (market-data) | top bar mid / bid / ask (`useTicks`, smoothed to 1 s) |
| `/ws/vol` | `vol_update` | end of each vol scan (about 3 min in market hours) | invalidation beat: the desk re-fetches its surface snapshots (throttled to 30 s) |
| `/ws/risk` | `risk_update` | end of each risk cycle (about 2 s) | invalidation beat for the risk and portfolio snapshots (throttled to 15 s) |
| `/ws/orders/{structure_id}` | `orders:<structure_id>` | each order status, fill, rejection, cancel or unwind of that structure (execution) | the order ticket while a submit is working |
| `/ws/positions` | `positions` | a position sync that upserted or closed rows, and the monitor's MTM snapshot per position | positions table patches (`positions_changed`), MTM ignored |
| `/ws/account` | `account` | each account snapshot of the execution engine | cash / margin panels (`account_snapshot.latest` = `GET /portfolio/account` latest) |
| `/ws/spot_orders` | `spot_orders` | each spot order change | spot blotter rows (`row` = one `GET /trade/spot-orders` row) |
| `/ws/exit_alerts` | `exit_alerts` | each exit alert the position monitor raises | not read by the desk today; for tools |
